# Inactive D1 scaffold

These original Cloudflare D1/Drizzle files are retained unchanged because Phase 1
must preserve database source. They are not imported by the Express application,
not included in its TypeScript build, and do not configure the PostgreSQL database.
They are examples, not runnable parts of this application; their old optional
Cloudflare/Drizzle dependencies are deliberately not added to the active packages.
